# Les Petits Chemins Citoyens · site du festival

Site officiel du festival **Les Petits Chemins Citoyens**, un festival gratuit et accessible, organisé par l'association Le Pré de la Bataille le 4 juin 2026 au Quartier Libre, à Rouen.

**En ligne :** https://festival-les-petits-chemins.com

## Le projet

Le festival avait besoin d'un site simple pour présenter l'événement, publier le programme et les infos pratiques, et permettre aux gens de s'inscrire.

Le site a été réalisé en équipe, dans le cadre du **projet citoyen du CESI**. L'association a été satisfaite du résultat et souhaite garder le site.

## Pages

- **Accueil** : présentation du festival, compte à rebours, accessibilité, lieu
- **Programme**
- **Infos pratiques**
- **Inscription**
- **Mentions légales** et politique de confidentialité

## Stack

- [Next.js 16](https://nextjs.org) (App Router) et React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion pour les animations
- Lucide pour les icônes

## Lancer le projet en local

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000.

Build de production :

```bash
npm run build
npm start
```

## Déploiement

Le site est hébergé sur [Vercel](https://vercel.com).
